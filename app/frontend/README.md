# FedTwin-RUL dashboard

This dashboard replays real NASA C-MAPSS FD004 engine histories. The bundled
`public/demo-data.json` is generated by the repository's trained FedTwin-RUL
checkpoint; it is not random or manually fabricated.

```powershell
# From the repository root (regenerate real replay data when needed)
.\.venv\Scripts\python.exe .\scripts\generate_dashboard_data.py

# Run the frontend
cd .\app\frontend
npm install
npm run dev
```

Use `npm run build` for a production bundle. Default visualization thresholds
are HEALTHY above 50 cycles, WARNING from 21–50, and CRITICAL at 20 or below.
They can be changed in the dashboard and will later map directly to Arduino LED
or relay commands.
